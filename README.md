# Dracula for Google Colab

> **This repository has been archived.**

This repository is no longer maintained. The official Dracula theme for [Google Colab](https://colab.research.google.com) is now available at:

**https://github.com/dracula/google-colab**

Please use the official repository for the latest version, installation instructions, updates, issues, and contributions.

## Previous Installation

The original installation instructions were available through [Dracula Theme](https://draculatheme.com/google-colab), using the [Stylus browser extension](https://add0n.com/stylus.html).
